# Mini Expression Language

Um interpretador simples para uma linguagem de expressões matemáticas, desenvolvido com **ANTLR** e **Python**.

O projeto define uma gramática própria para expressões aritméticas e operações de memória, gera o parser com ANTLR e executa as expressões usando um listener em Python.

## Funcionalidades

- Parsing de expressões matemáticas
- Suporte a operações aritméticas:
  - soma
  - subtração
  - multiplicação
  - divisão
  - divisão inteira
  - módulo
  - potenciação
- Operações de memória
- Avaliação baseada em stack
- Tratamento de erros para operações inválidas
- Gramática definida com ANTLR

## Exemplos de expressão

```txt
2 + 3 * 4
```

```txt
(10 - 2) / 4
```

```txt
2 ^ 3
```

## Estrutura do projeto

```txt
.
├── Calculadora.g4
├── CalculadoraListener.py
└── README.md
```

## Como funciona

A linguagem é definida no arquivo `Calculadora.g4`, que contém as regras léxicas e sintáticas utilizadas pelo ANTLR.

O listener em Python percorre a árvore sintática gerada pelo parser e executa as operações encontradas nas expressões.

Durante a execução, o projeto utiliza uma stack para armazenar valores intermediários e calcular o resultado final das expressões.

# Mini Expression Language

A simple interpreter for a mathematical expression language, built with **ANTLR** and **Python**.

The project defines a custom grammar for arithmetic expressions and memory operations, generates the parser with ANTLR, and evaluates expressions using a Python listener.

## Features

- Mathematical expression parsing
- Support for arithmetic operations:
  - addition
  - subtraction
  - multiplication
  - division
  - integer division
  - modulo
  - exponentiation
- Memory operations
- Stack-based evaluation
- Error handling for invalid operations
- Grammar defined with ANTLR

## Expression examples

```txt
2 + 3 * 4
```

```txt
(10 - 2) / 4
```

```txt
2 ^ 3
```

## Project structure

```txt
.
├── Calculadora.g4
├── CalculadoraListener.py
└── README.md
```

## How it works

The language is defined in the `Calculadora.g4` file, which contains the lexer and parser rules used by ANTLR.

The Python listener walks through the parse tree generated by the parser and executes the operations found in each expression.

During execution, the project uses a stack to store intermediate values and compute the final result of each expression.

## Technologies

- Python
- ANTLR
- Parsing
- Expression interpretation
- Stack-based data structure

## Purpose

This project was developed as a practical study of interpreter construction, formal grammars, and expression processing.

The main idea is to demonstrate how a small language can be defined, parsed, interpreted, and executed using ANTLR and Python.
